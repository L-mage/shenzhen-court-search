# 深圳市法院法官公务电话查询系统

可交互的在线查询工具，支持按法官姓名、法院名称、职能部门、案件类型、区县等多维度筛选，快速查找深圳市各级法院法官的公务电话。

## 在线访问

[https://L-mage.github.io/shenzhen-court-search/](https://L-mage.github.io/shenzhen-court-search/)

## 功能特性

- **关键字搜索** — 支持法官姓名、法院名称、庭室名称、电话等
- **多维度筛选** — 职能部门（立案庭/审判庭/执行局/派出法庭）、案件类型（12 种）、区县（9 个）、法院名称（11 个）
- **一键复制** — 点击复制按钮直接复制公务电话
- **响应式布局** — 适配桌面端和移动端
